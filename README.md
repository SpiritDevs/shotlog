# shotlog

A React library for in-app Support Logs with annotated Screenshots and server-side Email / Webhook delivery.

- [Package README](packages/shotlog/README.md): installation, setup, public API usage, and security.
- [Playground](apps/playground): run `pnpm install` then `pnpm dev` to try the library locally.
- [Docs](docs): architectural decisions and development plans.
- [CONTEXT.md](CONTEXT.md): domain glossary and design overview.
